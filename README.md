# Astros Fan Community (prototype)

日本のHouston Astrosファンの交流を目的とした大学制作課題用の試作版です。

## 機能
- 掲示板：投稿・返信・削除（localStorage）
- 試合トーク：試合名ごとのコメント（localStorage）
- ファン投票：ブラウザ内で集計（複数回投票可能）
- 試合結果予想：予想の保存・削除（自動答え合わせなし）
- 選手一覧：players.jsonを読み込み、お気に入り登録（localStorage）
- 選手比較：選手の基本情報比較（成績比較は未実装）
- チーム情報

## 起動方法
GitHub Pagesへ公開するか、ローカルHTTPサーバーで開いてください。`file://`では`fetch()`が失敗する場合があります。

## 重要な制限
現在、投稿・返信・投票・予想はブラウザ内だけで動作し、他のユーザーとは共有されません。ユーザー認証、投稿者本人確認、通報、管理者モデレーション、レート制限、バックエンドDBは未実装です。公開型のコミュニティとして運用する前に追加が必要です。

選手情報は動作確認用のサンプルであり、リアルタイム更新ではありません。API利用許諾が確認できるまでは外部データの自動取得を行わないでください。

## 既存リポジトリに適用
ZIPを解凍して中身のファイルを`astros-app`にコピーします。既存ファイルはバックアップしてから置き換えてください。既存の`.github`ディレクトリは削除しないでください。
